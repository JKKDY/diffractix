# Wiki

The wiki will cover the optics behind Diffractix. It will start with Maxwell's
equations, then explain the approximations that lead to ray optics and Gaussian
beams. It will connect those models through ABCD matrices and show how spaces,
lenses, and refractive interfaces change the light.

For a short introduction to the model used in Diffractix, see
[The optical model](../guide/overview.md#the-optical-model).
