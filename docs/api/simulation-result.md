# Simulation result

Inspect the numerical result of [Simulation.run()](simulation.md#diffractix.Simulation.run). Use `result[element]` to inspect a stage and its incoming and outgoing states.

The [results guide](../guide/results.md) shows how to run a system, read its stages, and plot the trace.
