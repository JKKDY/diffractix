# Examples

Each example is a complete Python script. Start with the ray example to learn
the workflow, then choose a design or a plotting example.

| Example | What it shows |
| --- | --- |
| [Focus a ray](focus-a-ray.md) | Build a system, choose a focal length, and read the solution. |
| [Plot a propagation trace](plotting.md) | Compare a ray, a ray bundle, and a Gaussian beam in the same system. |
| [Expand a Gaussian beam](beam-expander.md) | Match two beam properties while limiting length and beam radius at the lenses. |
| [Focus a Gaussian beam](beam-focusing.md) | Move a lens while keeping the workpiece at a fixed position. |
| [Match two fiber modes](fiber-mode-matching.md) | Build a reusable lens package and compare mode overlap before and after optimization. |
| [Deliver a beam to several stations](multistation-delivery.md) | Optimize a larger system with fixed stations, movable lenses, and shared limits. |

Install Diffractix with `python -m pip install diffractix`. Download the script
linked on the example page and run it with Python. You can also run the commands
shown on each page from the repository root.
